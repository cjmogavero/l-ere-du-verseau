# L’Ère du Verseau

An art and writing collective bringing together visual art, poetry, literary articles, places we knew, and diary entries.

[Visit the live website](https://reliable-designers-916768.framer.app/)

## Website and visual identity

The site is designed and maintained in Framer. A pale aqua header, cream background, brown serif typography, and an Aquarius-inspired pouring-vessel logo give its different sections a consistent identity.

The project notes document the website’s design, navigation, branding, maintenance, and ongoing refinements. Artwork creation and uploading are handled separately.
